## 📁 Projects

### 🎬 Bollywood Movies Analytics Dashboard

**File:** `Bollywood_movie_dashboard.pbix`

This is one of my recent Power BI projects, where I worked with Bollywood movie data and created an interactive dashboard.

I wanted to explore questions such as:

* How are movies performing at the box office?
* Which movies have the highest collections?
* How does the budget compare with box office collection?
* Which directors have the highest total box office collection?
* How are movies distributed across different genres?
* What is the average IMDb rating for different genres?
* How are movies distributed across OTT platforms?
* Which months have more movie releases?
* How many movies are classified as Hit, Flop, Average, or Blockbuster?

The dashboard includes **KPI cards, slicers, line charts, bar charts, donut charts, a scatter plot, and a detailed movie table**.

This project helped me practice **DAX, data visualization, dashboard designing, and interactive filtering** in Power BI.
